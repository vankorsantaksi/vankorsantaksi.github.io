# Van Korsan Taksi

Van korsan taksi için havalimanı göl kıyısında, şehre bitişiktir: Tuşba'dan 7, İpekyolu'ndan 8, Edremit'ten 12 kilometre. Şehir içi transfer kısa sürer; uzun yollar göl çevresine ve sınıra doğrudur. Başkale 117 kilometreyle en uzak ilçedir.

Akdamar Adası'na tekneler Gevaş iskelesinden kalkar; Gevaş 36 kilometre, 27 dakikadır ve araç iskelede bekler. Van Kalesi ile kahvaltı salonları şehir içindedir. Muradiye Şelalesi 89 kilometre uzaktadır. İran'dan gelen ziyaretçi Kapıköy'den alınır.
